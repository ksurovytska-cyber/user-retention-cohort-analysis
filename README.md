# user-retention-cohort-analysis
# Project Overview
This project analyzes user retention using cohort analysis. The goal was to compare retention behavior between promo users and organic users.

# Technologies
- SQL
- PostgreSQL
- DBeaver
- Google Sheets
- Pivot Tables
- Slicers
- Cohort Analysis
- Retention Rate

# Tasks
- Cleaned and transformed inconsistent date formats using SQL.
- Joined user and event tables by user ID.
- Filtered invalid records, NULL values, and test events.
- Calculated cohort month, activity month, and month offset.
- Aggregated unique users by promo status, cohort month, and month offset.
- Exported SQL results to Google Sheets.
- Built cohort tables and Retention Rate visualization.
- Added slicer filtering by promo and organic users.

# Result
Created an interactive cohort analysis report that shows user retention dynamics and compares acquisition quality between promo and organic users.
